## Description longue

### FR

**WP_Snippets** est une collection de snippets WordPress prêts à l'emploi, centrés sur la productivité admin et les workflows éditoriaux : calendrier de programmation, détection d'articles sans image, export Markdown RAG et plus, avec un workflow de synchronisation vers WordPress.

#### ✨ Fonctionnalités clés
- **Base de snippets prête à l'emploi** — snippets actifs dans `snippets/canonical/`, historique et variantes dans `snippets/archive/`
- **Calendrier éditorial (V26/V28)** — vue mensuelle, featured images, drag & drop, créneaux prioritaires et réallocation des brouillons dès aujourd'hui
- **Notification de quota quotidien (V28)** — notif flottante permanente sur toutes les pages admin indiquant le manque d'articles pour atteindre l'objectif du jour
- **Créneau automatique dans l'éditeur** — à l'ouverture d'un article dans Gutenberg, remplace « immédiatement » par le prochain créneau libre du calendrier
- **Détection des articles sans image mise en avant** — filtre dans la liste, sous-menu « Sans image » avec compteur et page dédiée
- **Sous-menu « Articles planifiés »** — dans la barre latérale sous Articles, avec badge du nombre d'articles planifiés
- **Export RAG Markdown** — un fichier `.md` par article + `INDEX.md` dans un ZIP, avec métadonnées complètes
- **Curseurs live et stats (2026.09)** — curseurs live partagés sur tout le site, page standalone `/statistiques/` avec graphiques SVG
- **Workflow de synchronisation WordPress** — comparaison, archivage des inactifs et récupération des snippets actifs via `CODE_SNIPPETS_SYNC/`

### EN

**WP_Snippets** is a collection of ready-to-use WordPress snippets focused on admin productivity and editorial workflows: scheduling calendar, missing-image detection, RAG Markdown export, and more, with a sync workflow back to WordPress.

#### ✨ Key features
- **Ready-to-use snippet base** — active snippets in `snippets/canonical/`, history and variants in `snippets/archive/`
- **Editorial calendar (V26/V28)** — month view, featured images, drag & drop, priority slots, and draft reallocation starting today
- **Daily quota notification (V28)** — permanent floating notice on all admin pages showing how many posts are missing to hit the day's goal
- **Automatic editor slot** — when opening a post in Gutenberg, replaces "immediately" with the next free calendar slot
- **Missing featured image detection** — list filter, "No Image" submenu with counter, and a dedicated page
- **"Scheduled Posts" submenu** — in the left sidebar under Posts, with a scheduled-count badge
- **RAG Markdown export** — one `.md` file per post + `INDEX.md` in a ZIP, with full metadata
- **Live cursors & stats (2026.09)** — shared live cursors site-wide, standalone `/statistiques/` page with SVG charts
- **WordPress sync workflow** — compare, archive inactive, and pull active snippets via `CODE_SNIPPETS_SYNC/`
